# خطتي الأكاديمية — ويب أبليكيشن

خطط دراسية تفاعلية لقسم الرياضيات وعلوم الحاسب، كلية العلوم — جامعة الإسكندرية.
تشتغل **بدون إنترنت** وتتثبّت على شاشة الموبايل كأيقونة عادية.

---

## 🚀 الرفع على GitHub Pages (5 دقايق)

```bash
# 1) جوه مجلد المشروع
git init
git add .
git commit -m "خطتي الأكاديمية — أول إصدار"

# 2) اربطه بالريبو بتاعك
git branch -M main
git remote add origin https://github.com/USERNAME/REPO.git
git push -u origin main
```

بعد كده على GitHub:
1. **Settings** ← **Pages**
2. تحت **Source** اختار **Deploy from a branch**
3. **Branch:** `main` و **Folder:** `/ (root)` ← **Save**
4. استنى دقيقة، هيطلعلك لينك: `https://USERNAME.github.io/REPO/`

> ملف `.nojekyll` موجود بالفعل — مهم عشان GitHub مايتجاهلش المجلدات.

### ⚠️ مهم جدًا: HTTPS شرط أساسي
الشغل بدون نت (Service Worker) **مايشتغلش** إلا على `https://` أو `localhost`.
GitHub Pages بيوفّر HTTPS تلقائيًا، فتمام. بس **لو فتحت الملفات بالدوبل كليك
(`file://`) الشغل بدون نت مش هيشتغل** — ده طبيعي ومش عيب في التطبيق.

### تجربة محلية قبل الرفع
```bash
python3 -m http.server 8000
# افتح: http://localhost:8000
```

## 📲 التثبيت على الموبايل

| الجهاز | الخطوات |
|--------|---------|
| **أندرويد (كروم)** | اضغط `⋮` ← «تثبيت التطبيق» — أو من صفحة `install.html` فيه زر مباشر |
| **آيفون (سفاري)** | زر المشاركة `↑` ← «إضافة إلى الشاشة الرئيسية» |
| **كمبيوتر** | أيقونة `⊕` في شريط العنوان |

صفحة `install.html` بتكتشف جهازك وبتوريك الخطوات الصح لوحدها.

### 🔴 مشكلة اللينك من واتساب — اقرأ ده
لما تبعت اللينك على **واتساب أو فيسبوك أو إنستجرام**، بيفتح جوه *متصفح داخلي*
مش المتصفح الحقيقي. وهناك:
- التثبيت **مش بيشتغل**
- الشغل بدون نت **مش بيشتغل**
- التقدم **بيضيع** لما تقفل الشاشة

**التطبيق بيكتشف ده لوحده** ويعرض شاشة فيها:
- زر **«افتح في كروم»** بيفتح كروم فعليًا (بـ `intent://` على أندرويد)
- زر نسخ اللينك
- تعليمات مصوّرة للآيفون
- وزر «كمّل هنا برضو» لو مستعجل — مع تحذير ثابت إن التقدم مش محفوظ

لما تشارك اللينك، **قول للناس يفتحوه من كروم أو سفاري**.

## 🧩 إضافة صفحة جديدة (3 خطوات)

### 1) انسخ القالب
```bash
cp -r modules/_template modules/schedule
```
واكتب اللي إنت عايزه جوه `modules/schedule/index.html` — HTML و CSS و JS عادي.
القالب فيه كل الكلاسات الجاهزة (كروت، أزرار، شرائح، جداول، شرائط تقدم).

### 2) ضيفها في `registry.json`
```json
{
  "id": "schedule",
  "title": "جدول المحاضرات",
  "short": "الجدول",
  "icon": "🗓️",
  "desc": "وصف قصير يظهر في كارت الداشبورد.",
  "entry": "modules/schedule/index.html",
  "color1": "#22d39a",
  "color2": "#00e5ff",
  "storageKeys": ["csScheduleData_v1"],
  "tags": ["جدول", "محاضرات"],
  "cache": true
}
```
وزوّد `version` فوق في نفس الملف.

### 3) ضيف المسار في `sw.js`
```js
const CACHE_VERSION = 'v1.0.1';        // ← زوّد الرقم ده

const PRECACHE = [
  // ...
  './modules/schedule/index.html',     // ← ضيف السطر ده
];
```

**خلاص.** الصفحة هتظهر في الداشبورد، تشتغل بدون نت، وتدخل في البحث.

### الحفظ في صفحتك الجديدة
استخدم `localStorage` عادي، بس **خلّي المفتاح يبدأ بـ `cs` وبعدها حرف كبير**:
```js
localStorage.setItem('csScheduleData_v1', JSON.stringify(myData));
```
كده التطبيق بيلقطه **تلقائيًا** ويعمله نسخة احتياطية ويحطه في التصدير/الاستيراد —
من غير ما تعدّل أي ملف تاني.

عايز اسم عربي واضح في صفحة التشخيص؟ ضيفه في `assets/store.js` جوه `WATCHED_KEYS`.

## 🛟 النسخ الاحتياطي — أهم حاجة تعرفها

بياناتك محفوظة **على جهازك بس** (مفيش سيرفر). والمتصفحات بتمسح بيانات المواقع في حالات:

| الحالة | الجهاز |
|--------|--------|
| مساحة الجهاز قلّت → النظام يمسح بيانات المواقع | أندرويد |
| 7 أيام عدم استخدام → سفاري يمسح كل حاجة | **آيفون / آيباد** |
| المستخدم مسح بيانات المتصفح | الكل |

**الحمايات المبنية في التطبيق:**
1. **مرآة تلقائية على IndexedDB** — أقوى من localStorage. لو localStorage اتمسح،
   التطبيق **يرجّع بياناتك لوحده** أول ما تفتحه ويقولك.
2. **`navigator.storage.persist()`** — بيطلب من النظام مايمسحش بياناتنا.
3. **تصدير/استيراد JSON** — الحماية الأكيدة. من `diagnostics.html` أو من زر
   «نسخة احتياطية» في شريط أي خطة.

> 💡 **لو على آيفون:** نزّل نسخة احتياطية كل أسبوعين. دي حمايتك الوحيدة الحقيقية.

## 🔒 ضمان سلامة بياناتك الأكاديمية

**قاعدة المشروع:** ولا رقم أكاديمي واحد اتغيّر. لا ساعات، لا أكواد مواد،
لا متطلبات سابقة، لا `gradeScale`، لا `CATEGORY_TARGETS`، لا شروط السبيشيال،
لا مرتبة الشرف، لا `LOCKED_TERM_COURSES`، ولا نص ملاحظة واحد.

**التعديل الكامل على كل ملف = 3 أسطر متغيّرة و24 سطر مضاف:**
1. `data-module="..."` على وسم `<html>`
2. لينك Google Fonts → الخطوط المحلية (عشان الشكل مايبوظش بدون نت)
3. 3 أسطر `<script>` قبل `</body>` (الجسر)
4. لينكات الـ PWA في `<head>`

**التحقق آلي — شغّله في أي وقت:**
```bash
python3 tools/verify_data.py
```
بيقارن كل موديول بالأصل: hash لكل بلوك بيانات، عدد المواد، مجموع الساعات لكل
تصنيف، كل سطر مادة بالحرف، وبيرفض أي فرق مش من التعديلات المسموحة أعلاه.

```bash
node tools/test_logic.js      # 64 اختبار للمنطق
```

### لو عدّلت ملفاتك الأصلية بعدين
```bash
# 1) حدّث الملف في originals/
# 2) أعِد التحويل:
python3 tools/patch_modules.py
# 3) اتأكد:
python3 tools/verify_data.py
# 4) زوّد CACHE_VERSION في sw.js
```

## ❓ مشاكل شائعة

**«التطبيق مش شغال بدون نت»**
افتحه وإنت متصل مرة واحدة واستنى رسالة «التطبيق بقى شغال بدون نت». وافحص من
`diagnostics.html` إن الملفات محفوظة كلها.

**«مفيش زر تثبيت»**
غالبًا فاتح من واتساب/فيسبوك. افتحه من كروم أو سفاري. على الآيفون مفيش زر
تلقائي أصلًا — لازم «إضافة إلى الشاشة الرئيسية» من سفاري.

**«تقدمي ضاع»**
افتح `diagnostics.html` — لو IndexedDB فيه نسخة، التطبيق بيرجّعها لوحده.
وإلا استورد آخر نسخة احتياطية نزّلتها.

**«الخط شكله غريب»**
افحص إن مجلد `assets/fonts/` اترفع كامل (9 ملفات `woff2`).

**«الصفحة الجديدة مش ظاهرة»**
راجع إنك ضفتها في `registry.json` بـ JSON صحيح، وزوّدت `CACHE_VERSION` في
`sw.js`، وحدّثت الصفحة.
